# FunHouse — Play Money Arcade

Eine komplette, lokal laufende Party-Arcade-Webseite für Freunde. Die App nutzt ausschließlich **fiktive Fun Coins (FC)** und enthält keine Zahlungs-, Einzahlungs-, Auszahlungs- oder Echtgeld-Funktion.

## Start

Einfach `index.html` im Browser öffnen. Für lokale Entwicklung ist auch ein beliebiger statischer Server geeignet, z. B.:

```bash
python3 -m http.server 8080
```

Danach `http://localhost:8080` öffnen.

## Enthalten

- 60+ Minigame-Einträge mit spielbaren, unterschiedlichen Mechaniken
- Fun-Coin-Wallet mit Daily Bonus und Reset
- Private Room-Codes
- Freunde, Presence und kleine Party-Profile
- Lokaler Chat mit Channels
- Rangliste und Quests
- Profil- und Appearance-Einstellungen
- Lokale Admin-Console
- Game Flags, Economy Controls, Player-Mute-Log und Audit-Log
- Responsive Dark-UI für Desktop und Mobile
- Persistenz über `localStorage`
